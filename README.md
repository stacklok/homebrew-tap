# homebrew-tap

Stacklok's Homebrew tap.

The casks in [`Casks/`](Casks) are generated by each project's release
workflow (GoReleaser) and committed here automatically. Don't edit them by
hand: the next release overwrites them.

## Installation

```bash
brew install stacklok/tap/<cask>
```

or tap once, then install by name:

```bash
brew tap stacklok/tap
brew install <cask>
```

where `<cask>` is one of the casks below. They work on macOS and Linux, on
both Intel/AMD64 and ARM64.

## Available casks

| Repository | Cask | Installs | Description |
|---|---|---|---|
| [toolhive](https://github.com/stacklok/toolhive) | [thv](Casks/thv.rb) | `thv` | ToolHive (thv) is a lightweight, secure, and fast manager for MCP (Model Context Protocol) servers |
| [mecatl](https://github.com/stacklok/mecatl) | [mecatl](Casks/mecatl.rb) | `mecated`, `mecatui` | Agent harness for cloud-native workloads, with server and terminal UI |
| [modelith](https://github.com/stacklok/modelith) | [modelith](Casks/modelith.rb) | `modelith` | Tooling for authoring, validating, and rendering domain models |

## Moving from the old formulas

These packages used to be published as formulas. If you installed one
of them that way, the next `brew update` switches it to the cask
automatically, because `tap_migrations.json` lists all three. Homebrew then
leaves the old formula's files in place but unlinked. Remove them when
convenient:

```bash
brew uninstall --formula --force <name>
```
